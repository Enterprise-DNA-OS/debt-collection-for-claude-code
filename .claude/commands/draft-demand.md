# draft-demand

Draft a letter asking for payment, addressed to the representative if there is one. Refuses for a bankrupt debtor, an open dispute or a request for no contact. A statute-barred debt gets a warning not to mention legal action. Written to drafts/, never sent.

Run `node scripts/collections.mjs draft-demand <ref>`. Add `--json` when you need every field. Resolve the account or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Fill the bracketed lines with the operator. Never add a threat the agency does not intend and cannot carry out (RG 96 part 2 s 19-21).
