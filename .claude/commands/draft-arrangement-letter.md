# draft-arrangement-letter

Draft the letter confirming an arrangement, with every payment date. Written to drafts/, never sent.

Run `node scripts/collections.mjs draft-arrangement-letter <ref>`. Add `--json` when you need every field. Resolve the account or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
