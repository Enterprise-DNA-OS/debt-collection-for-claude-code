# disputes

Open disputes about liability, amount or identity, oldest first.

Run `node scripts/collections.mjs disputes`. Add `--json` when you need every field. Resolve the account or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Say what is needed from the client for each one.
