# documents

Run `npm run docs`, or `npm run docs -- remittance-statement` for one kind, or `npm run docs -- debtor-statement <id-prefix>` for one account. Files land in `docs-out/`. Change the agency name, colours and logo in `brand.json`. Check each one before it goes out; nothing is sent.
