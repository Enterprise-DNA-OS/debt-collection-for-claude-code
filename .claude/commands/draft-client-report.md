# draft-client-report

Draft a client's report: collected in 30 days, money in trust, every open account and the disputes we need their help with. Written to drafts/, never sent.

Run `node scripts/collections.mjs draft-client-report <client code>`. Add `--json` when you need every field. Resolve the account or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
