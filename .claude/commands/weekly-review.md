# weekly-review

Write the Monday review from attention, compliance breaches, the worklist and trust money.

Run `node scripts/collections.mjs weekly-review`. Add `--json` when you need every field. Resolve the account or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Summarise in five lines: what is broken, what breached a rule, how many accounts can be worked, what trust money is due, who owns each.
