# contacts

Every contact and attempt on one account in the debtor's local time, with any rule each one broke.

Run `node scripts/collections.mjs contacts <ref or debtor>`. Add `--json` when you need every field. Resolve the account or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Count contacts made, not attempts, when talking about the limit.
