# statute

Debts that are statute-barred or will be within 180 days (or --days=N), with the rule and the date the period runs from.

Run `node scripts/collections.mjs statute [--days=<n>]`. Add `--json` when you need every field. Resolve the account or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

For a debt about to be barred, the choices are legal action now, a written acknowledgement, or accepting it. For one already barred, never say or imply legal action.
