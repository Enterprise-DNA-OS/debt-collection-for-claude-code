# history

Everything about one account: debtor and restrictions, balance, the statute-barred date, ledger, arrangements, disputes, contacts and recent activity.

Run `node scripts/collections.mjs history <ref or debtor>`. Add `--json` when you need every field. Resolve the account or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Read this before any write or draft about the account.
